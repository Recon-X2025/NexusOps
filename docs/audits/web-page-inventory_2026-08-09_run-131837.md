## Verification method (what "verified" means here)

Seven sub-agents produced first-draft page reports; **their prose was treated as unverified hypotheses, not fact.** Every objective column below was then rebuilt from a first-party extraction I ran directly against the source and cross-checked:

- **Mutations per page** — extracted from all 371 `useMutation` sites (`rg` → per-file attribution). This is the source of every "Actions" line; it already corrected agent omissions (e.g. `secretarial.resolutions.pass`, `ai.agentInvoke`, `esign.createRequest`).
- **Real-vs-placeholder** — extracted from all 333 `useQuery` sites per page + the zero-tRPC page set. A page renders real data iff it (or a child component it delegates to) issues a tRPC query.
- **Reachability** — computed against three navigation surfaces (below) plus per-route `rg` linker checks; every "unreachable" and "url-only" verdict was confirmed by grep, and every drill-down parent→detail link was confirmed present.
- **Procedure coverage** — computed as a set difference: the authoritative registry `apps/web/src/lib/trpc-procedure-rbac.generated.ts` (**824 registered procedures**) minus every `trpc.*`/`utils.*` call in `apps/web/src` (prefix-matched). Result: **269 uncalled by any web page**. This diff is mine, not an agent enumeration.
- **Flagged no-op / placeholder items** — each one below was opened and confirmed in source (line-cited).

"Coverage" = called by the **web app** (`apps/web`). A procedure may still be used by `apps/mac` (super-admin console), workers, or tests; that does not count as web-page coverage.

## Navigation surfaces (reachability model)

A route is reachable **from navigation** if it appears in any of these three in-app surfaces:
1. **Sidebar** — `apps/web/src/lib/sidebar-config.ts` (`SIDEBAR_GROUPS`), rendered by `app-sidebar.tsx`.
2. **Header** — `app-header.tsx` (adds `/app/dashboard`, `/app/admin`, `/app/notifications`, `/app/profile`, `/app/tickets/new`).
3. **⌘K command palette** — `command-palette.tsx` (adds `/app/agent` and `/app/reports`, which are **not** in the sidebar).

Tags used below:
- **`NAV`** — in sidebar/header menu.
- **`NAV (⌘K only)`** — only in the command palette (not sidebar/header).
- **`NAV (drill-down)`** — not a menu item, but reached by the primary flow (clicking a row/`New` button) on a menu-reachable parent. Linker confirmed.
- **`URL-only`** — not in any menu; reachable only via a secondary in-page link (an inline sentence, a quick-link tile, or an internal island). Linker named.
- **`UNREACHABLE`** — no inbound link anywhere in `apps/web/src` (grep-confirmed). Reachable only by typing the URL. Redirect stubs are marked as such.
